# 06. Состояние и план подключения TravelGo

Рабочая ветка бэкенда — `Kossa-Soft/TravelGo_APP_BEK:dev-main`. Контракт доступных мобильных методов — [openapi.yaml](../../openapi.yaml). Базовый адрес тестовых сборок — `https://travel-go-api.kossasoft.com/v1`.

План сверён с мобильной веткой `main` на коммите [`ca35270`](https://github.com/Kossa-Soft/TravelGo_APP/commit/ca35270). Документы [02](02-content-model.md), [03](03-mobile-content-api.md), [04](04-admin-api.md), [07](07-legal-pages.md) и [08](08-nearby-and-travelgo-content.md) синхронизированы с этой версией. При расхождении требований к контенту приоритет у [08](08-nearby-and-travelgo-content.md).

## Этапы

| Этап | Статус и следующая проверка |
|---|---|
| 1. Авторизация и SMS | API на staging, в приложении `auth: true`. Регистрация, вход, восстановление, обновление токенов и выход описаны в [01](01-auth.md). |
| 2. Профиль и фото | API на staging, в приложении `profile: true` и `avatar: true`. Экран удаления аккаунта подключён. Для мобильной приёмки осталось подтвердить смену номера с реальной SMS и успешно удалить отдельный тестовый аккаунт. |
| 3. Админка контента | Развёрнут и принят. Раздел TravelGo, редактирование и публикация контента, права администраторов, карта и журнал. Административные операции описаны в [04](04-admin-api.md). |
| 4. Контент в приложении | Импорт и мобильные методы из [08](08-nearby-and-travelgo-content.md) реализованы. Для приёмки нужны развёртывание, импорт на staging и переключение приложения после проверки. |
| 5. Уведомления | Экраны готовы. `notifications: false` до сдачи серверного списка, настроек, отметок о прочтении и счётчика. Рассылки и push подключаются отдельной поставкой. Требования в [05](05-notifications.md). |
| 6. Подписка PRO | Покупка, восстановление и проверка подписки на сервере согласуются отдельным этапом. |

Публичные [`/privacy` и `/terms`](07-legal-pages.md) нужны к публикации приложения в сторах. Тексты и переводы предстоит утвердить.

## Этап 4 и мобильный каталог

- Стартовый каталог взят из мобильного коммита `ca35270`. Набор включает 8 стран, 16 регионов, 16 городов, 184 места и 52 маршрута. [JSON и описание формата](https://github.com/Kossa-Soft/TravelGo_APP/tree/ca35270/content)
- После миграций запускаем `php artisan travelgo:import`. `--dry-run` проверяет каталог с откатом, `--without-media` подходит для теста без скачивания фото. Повторный импорт сохраняет UUID и обрабатывает только изменившиеся записи. Слаги остаются публичными ID импортированных объектов, поэтому старые закладки совместимы с API. Обложка маршрута берётся из места `coverPlaceId` и сохраняет `coverCredit`.
- Первая мобильная поставка включает `GET /v1/geo/locate`, `GET /v1/places/nearby`, `GET /v1/places/in-area`, `GET /v1/places/{id}`, `GET /v1/routes/nearby`, `GET /v1/routes/{id}` и `GET /v1/cities` для ручного выбора города. Ответы включают `address`, `coverCredit` и координаты городов в `suggestion`. Серверные закладки доступны через `/v1/me/saved-routes`. Импорт локальных закладок принимает прежние слаги.
- В запросах «Рядом» координаты используются для расчёта ответа без сохранения в базе и логах. Ответы с `isSaved` привязаны к аккаунту и перепроверяются при каждом запросе с токеном. Для определения страны за пределами городской зоны используются локальные границы Natural Earth.
- `content` переключаем после публикации стартового набора на staging и появления мобильных методов в [openapi.yaml](../../openapi.yaml). На устройстве проверяем текущий город, соседние города, подсказку вне зоны и выбор города вручную.

## Правила мобильной интеграции

- Отправляем `Accept: application/json` и `Accept-Language: uk|en|de|es|fr`. Для закрытых методов передаём `Authorization: Bearer <accessToken>`.
- После `401` от защищённого метода приложение один раз обновляет токены через `POST /v1/auth/refresh` и повторяет запрос. При отказе обновления показывает вход.
- Тексты ошибок выбираем по полю `error.code`. Фото отправляем как `multipart/form-data`.
- Сдача API включает проверку на staging, актуальную версию `openapi.yaml` и прогон в приложении на iOS и Android. В замечании указываем метод, ответ, ожидаемое поведение и коммит бэкенда.
